# Archived Notes

This folder keeps historical notes, one-off benchmark email drafts, and early
profiling artifacts that are no longer part of the active development workflow.

These files are retained for project history, but the current working
documentation lives in the parent `docs/` directory:

- `docs/6co8_gpu_fabipb_milestone.md` — full-virus reproducibility record
- `docs/setup_rhs_and_gpu_tracking.md` — RHS and GPU implementation notes
- `docs/tabi_fmm_large_protein_diagnosis.md` — accuracy investigation
- `docs/gpu_backend_explained.md` — current GPU architecture
- `docs/benchmark_plan.md` and `docs/test_plan.md` — active validation plans
- `docs/dependencies.md` — build/runtime prerequisites

Archived categories:

- completed implementation plans and branch notes
- historical benchmark email drafts
- finished NanoShaper and CPU profiling analyses
- exploratory research notes not connected to the current PB solver
